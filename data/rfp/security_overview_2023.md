# Halcyon Data Security Overview
Last updated: 2023-03-14

## Encryption
Customer data is encrypted at rest with AES-256 and in transit with TLS 1.2.

## Data retention
Customer data is retained for 30 days after contract termination, then permanently deleted.

## Compliance
We are preparing for a SOC 2 audit and expect to begin in 2024.

## Testing
We run internal vulnerability scans quarterly.
